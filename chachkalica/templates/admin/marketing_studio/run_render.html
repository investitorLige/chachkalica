{# ----------------------------------------------------------------- preset #}

Preset

A saved look — everything under Boxes, Colour, Labels, What to show, Scene, Motion and Output file. Deliberately not the model or the pipeline: those come from the model's own recorded metadata. Save one with the button at the bottom of this form; rename or delete them under Render presets.

{# ------------------------------------------------------------------ boxes #}

Boxes

Corner brackets read as "tracking"; a plain rectangle reads as "detected". Both beat a hard box on close-up footage.

Pixels at 1080p — scaled to whatever the output resolution is.

0 is a sharp rectangle.

How far each corner mark runs along the box's sides — also sizes the crosshair's edge ticks and centre mark.

Gap between beads; the beads themselves follow the line thickness.

How much of each corner is cut away.

How far the bloom fans out past the line. Works best on dark footage with a saturated colour.

How far the hand wobbles. The wobble is fixed per class, not re-rolled each frame — a reseeded jitter boils like video noise.

A wash of the box's own colour inside it. Around 0.1 marks the subject without hiding it.

{# ------------------------------------------------------------------ colour #}

Colour

Each class takes a colour from this palette and keeps it across runs.

Pin specific classes to specific colours — brand colours, or the one class a clip is about. Everything else keeps the palette.

{# ----------------------------------------------------------------- labels #}

Labels

Falls back to inside the box wherever the chosen side would leave the frame.

Multiplier — 1.0 is sized for a 1080p frame.

{# ------------------------------------------------------------ what to show #}

What to show

Comma-separated. Blank draws every class the model returned. This hides boxes from the picture — it does not change what the model was asked or what it found.

The classes the selected model predicts. Pick one and every box drawn is labelled and coloured as that class, whatever the model actually said — each box keeps its own position and confidence. For a clip whose class names are not the ones to show an audience. This is only the picture: the job's recorded detections, the counts on the Inferred videos tab and Only these classes above all still go by what the model returned. {% if not class_choices %}Nothing to pick: no class list is on record for this model here — a bundle carries one in its manifest, a trained model on its row, an exported artifact in the sidecar beside it.{% endif %}

Percent of the frame's area. Drops the far-background specks that make a wide shot look noisy.

0 = no limit. Otherwise the highest-confidence N survive.

{# ------------------------------------------------------------------ scene #}

Scene

Darkens everything outside the boxes by this much. Pushes the eye onto the detections; heavy-handed above ~0.5.

A live "class × N" tally in one corner.

{# ----------------------------------------------------------------- motion #}

Motion

Eases each box toward its new position instead of snapping. Also what makes a frame stride above 1 look deliberate rather than choppy. Too high and the boxes lag behind the subject.

Frames a box takes to appear, and to stay on screen fading after the model stops returning it. Removes the single-frame flicker that makes a detection reel look broken; 0 draws exactly what each frame's model output says.

Marching crawls the dashes or dots around the box (pick the dashed or dotted outline for it); pulse breathes the line thickness on any outline.

Frames per cycle — at 25 fps, 25 is one cycle a second. Counted in rendered frames, so a re-render animates identically.

Neither knob invents a detection: smoothing moves boxes the model did return, and a fade-out is bounded by the frames set here. The Score threshold above is still what decides whether something is a detection at all. None of the three shows in the preview — a still has no motion to smooth, fade or animate — so set them by eye on the finished clip.

{# ----------------------------------------------------------------- output #}

Output file

0 keeps the source resolution. 1080 turns a 4K clip into something that can actually be sent to someone — the model still sees the full-resolution frame, only the rendered output shrinks.

x264 constant rate factor: lower is better and bigger. 18 is visually lossless, 20–23 is fine for sharing, above 28 shows on flat surfaces.

Save this look

Stores everything above (not the model or the pipeline) under that name, ready to pick from the Preset dropdown on the next clip. Saving over an existing name updates it — which is how you amend a preset after tweaking it.
