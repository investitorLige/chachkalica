0 runs the whole dataset. A cap takes an evenly spaced subset, so a small number still spans the dataset instead of grabbing its first N files. One answer costs about a second of GPU, so 10 000 images is hours.

Compares every answer against that image's YOLO label file: the classes the file annotates are looked for in the answer, and an image counts as a success when the answer names exactly those classes and no others. Needs a labels/ folder and a classes.txt.

The selected dataset has no labels/ folder — there is nothing to grade against. Run it ungraded, or label it first.
