People

The one population on this page where a false positive has an owner. Every person the measures pass found is one row, and every class is one yes/no question asked twice of them — is there a helmet on this person in the labels, and did the model say there was — so a person carrying nothing is evidence too. That is what precision, specificity and accuracy need in order to exist here and nowhere else on this page: a box tag has no row for the person the model did not fire on.

Cross-tab

One metric over every combination of two tags' values — the intersection, so a cell is the images, people or boxes answering both. The most specific scope wins: pair a person tag with anything and the grid scores people; pair a box tag with a frame tag and it scores boxes, with only the ground-truth-side metrics on offer. A person tag paired with a box tag keeps the people who own at least one box the box clause selected.

Custom slice

Any intersection of tag values, to whatever depth. Frame-only filters get the full metric set; add a box tag and the slice becomes a set of boxes, scored on recall.
