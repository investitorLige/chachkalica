Cross-tab

One metric over every combination of two tags' values — the intersection, so a cell is the images (or boxes) answering both. Pairing a box tag with anything makes the whole grid a box slice, with only the ground-truth-side metrics on offer.

Custom slice

Any intersection of tag values, to whatever depth. Frame-only filters get the full metric set; add a box tag and the slice becomes a set of boxes, scored on recall.
